# MacOps Toolkit

A collection of macOS system administration, troubleshooting, diagnostics, security, disc health, and automation tools developed as part of my hands-on IT training.

## Project Goals

- Automate common macOS administration tasks
- Develop practical Bash and Python scripting skills
- Troubleshoot system and network issues
- Generate system health and diagnostic reports
- Practice security and disk-health auditing
- Develop repeatable IT support workflows
- Document technical procedures and troubleshooting results

## Toolkit

### System Audit
Collects key macOS system information and generates a system health report.

### Network Diagnostics
Performs network connectivity and configuration checks to assist with troubleshooting.

### Security Audit
Checks selected macOS security settings and configurations.

### Disk Health
Collects disk and storage information for basic health and capacity analysis.

### Backup Automation
Provides automation for repeatable backup tasks.

### Full Health Check
Combines multiple diagnostic checks into a consolidated macOS health assessment.
